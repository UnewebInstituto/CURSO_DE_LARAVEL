Descripción de la falla:

Este error ocurre porque tu instalación de PHP en XAMPP no puede verificar el certificado SSL del sitio web de Composer, generalmente porque el archivo `curl-ca-bundle.crt` está desactualizado o no está siendo correctamente apuntado por tu configuración.

Aquí tienes el procedimiento paso a paso para corregirlo:

### 1. Descarga el archivo de certificados actualizado

Composer necesita un archivo de certificados actualizado para validar la conexión segura (HTTPS).

1. Ve a [curl.se/docs/caextract.html]
(https://curl.se/docs/caextract.html).

2. Haz clic en el enlace **[cacert.pem]** para descargar la versión más reciente del archivo.

### 2. Sustituye el archivo en tu XAMPP

Ahora debemos reemplazar el archivo antiguo que está dando problemas.

1. Navega a la carpeta indicada en tu error: `C:\xampp\apache\bin\`.


2. Busca el archivo llamado `curl-ca-bundle.crt`.
3. **Cámbiale el nombre** (por ejemplo, a `curl-ca-bundle.crt.bak`) para tener un respaldo.
4. Mueve el archivo `cacert.pem` que descargaste a esta misma carpeta (`C:\xampp\apache\bin\`).
5. **Renombra** ese `cacert.pem` a `cd` para que PHP lo reconozca bajo el nombre que espera.

### 3. Asegura la configuración en tu `php.ini`

Debemos verificar que PHP sepa dónde está este archivo.

1. Abre tu archivo `C:\xampp\php\php.ini`.

2. Busca la línea que comienza con `curl.cainfo`.

3. Asegúrate de que apunte exactamente al archivo que acabamos de colocar:
`curl.cainfo = "C:\xampp\apache\bin\curl-ca-bundle.crt"`
4. Busca también `openssl.cafile` y configúralo igual:
`openssl.cafile = "C:\xampp\apache\bin\curl-ca-bundle.crt"`
5. **Guarda los cambios** y cierra el archivo.

### 4. Verifica y vuelve a intentar

Para que los cambios surtan efecto en tu terminal:

1. Cierra todas las ventanas de la terminal (CMD o PowerShell) que tengas abiertas.
2. Abre una nueva terminal.
3. Intenta ejecutar el instalador de Composer nuevamente.

#### ¿Por qué esto funciona?

PHP tiene configuradas unas rutas de búsqueda por defecto (`default_cert_file`). Al poner tu archivo `curl-ca-bundle.crt` (con el nombre `cert.pem`) en esa ruta específica de `C:\Program Files\Common Files\SSL\`, PHP lo encontrará automáticamente sin necesidad de que el `php.ini` esté perfectamente sincronizado en todos sus parámetros.

NOTA IMPORTANTE:

Este error es muy común en entornos de Windows con XAMPP y ocurre porque la versión de PHP que utilizas desde la consola no puede validar el certificado SSL de `getcomposer.org` debido a un archivo `cacert.pem` desactualizado o mal configurado.

Para solucionar esto, sigue estos pasos en orden:

---

### 1. Descargar el certificado actualizado

PHP necesita un archivo actualizado que contenga las autoridades de certificación (CA) de confianza.

1. Ve a [curl.se/docs/caextract.html](https://curl.se/docs/caextract.html).
2. Haz clic en el enlace **cacert.pem** para descargar el archivo.
3. Guarda este archivo en una ruta permanente, por ejemplo: `C:\xampp\php\extras\ssl\cacert.pem` (si las carpetas no existen, créalas).

### 2. Configurar `php.ini`

Debes indicarle a tu consola qué archivo utilizar para verificar los certificados.

1. Abre el archivo indicado en tu error: `C:\xampp\php\php.ini`.
2. Busca la sección `[curl]` y `[openssl]`.
3. Busca la directiva `openssl.cafile`. Probablemente esté comentada (con `;` al principio). Descoméntala y asígnale la ruta del archivo que descargaste:

```ini
[openssl]
openssl.cafile = "C:\xampp\php\extras\ssl\cacert.pem"

[curl]
curl.cainfo = "C:\xampp\php\extras\ssl\cacert.pem"

```

*Nota: Asegúrate de guardar el archivo y cerrar cualquier consola que tengas abierta actualmente.*

### 3. Verificar la ruta de PHP

A veces, Windows está ejecutando una versión de PHP distinta a la de XAMPP (por ejemplo, una instalada por Laragon o una versión global anterior).

Para verificar qué versión está usando tu sistema, ejecuta esto en la terminal:
`where php`

Asegúrate de que la ruta que aparece sea la de tu carpeta de XAMPP (`C:\xampp\php\php.exe`). Si no es así, deberás actualizar la variable de entorno **PATH** en Windows para que apunte primero a la carpeta de PHP de XAMPP.

---

### ¿Persiste el problema? (Solución rápida temporal)

php composer-setup.php --no-check-certificate
